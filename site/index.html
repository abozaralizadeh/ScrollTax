ScrollTax

An iPhone app for people who want less social media. You sign up, your social media gets blocked, and opening it costs a small amount for a short window of time.

Early project, working name. Not released, takes no real money, and the real blocking hasn't run on a real iPhone yet. The screenshots below are from the simulator in demo mode.

How it works

  • You join by choice. You can leave for free, after a short wait.
  • The phone does the blocking with Apple's Screen Time tools, so it works even when the server is down.
  • One payment opens everything you blocked for a set time, 15 minutes by default. Then the block comes back by itself.
  • A daily limit on unlocks keeps it from turning into a way to spend more and more.
  • The price, the time, the daily limit and the leave wait are all settings.
  • A small backend keeps accounts and payment records. It holds nothing about which apps you block or how you use them.

Quick install

You need Node 24 or newer. For the iPhone app you also need Xcode and XcodeGen.

Backend:

cd backend
npm install
cp .env.example .env
# put a long random string in SESSION_SECRET (openssl rand -hex 32)
npm run dev

It starts in fake Apple mode on http://127.0.0.1:8787. Nothing paid is ever called.

iPhone app, in the simulator (demo mode, with a pretend blocker and a pretend purchase):

cd ios
xcodegen generate
open ScrollTax.xcodeproj

Run the tests:

cd backend && npm test
cd ios/Packages/ScrollTaxCore && swift test

For a Debian or Ubuntu server, run sudo ./setup_service.sh. It installs everything the first time, and updates and restarts on every run after that.

What's missing

  • Real blocking needs Apple's Family Controls approval and a real iPhone.
  • Real Sign in with Apple and App Store purchases are written but have only been tested against locally made keys.
  • There's no web demo. The product is an iPhone app, and Screen Time can't run in a browser.
