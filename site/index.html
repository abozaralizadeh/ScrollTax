How it works

Three steps, and one of them is free.

  1. 1

    Pick what to block

    You choose your social apps with Apple's own picker. Apple hands us private tokens, so we never learn which apps they are.

  2. 2

    Blocked, all day

    Open one of them and you hit the block. No streaks, no guilt messages, no fake countdowns. It's just closed.

  3. 3

    Pay, get 15 minutes

    Pay the toll through Apple and everything opens for 15 minutes. When the time's up, the block comes back on its own, even with the app closed.

What's in it

Built to be fair to the person paying.

Leaving is free

Ask to leave and the block comes off after a 24 hour wait. Or delete your account and it's gone straight away.

A daily limit

Four unlocks a day by default. After that the button stops working until midnight, so it can't turn into a money pit.

Works offline

The phone runs the rules. If the server is down or you have no signal, the block holds and a paid unlock still unlocks.

Moving the clock won't help

The 15 minutes run on the phone's uptime clock, not the date in Settings. Wind the date back and the timer doesn't care.

Nothing about your habits

No list of your apps, no usage stats, no reason for joining. The backend keeps an account and the payments, and that's it.

Your data, your copy

Download everything held about you as a file, from Settings. Delete it all in one tap. Payment records lose their link to you.

The price, before every payment

You see exactly what you're paying and what you get, every single time. Afterwards it's all in your history, refunds included.

The price, the minutes, the daily limit and the leave wait are settings, so anyone running their own copy can change them.

Install

Run it on your Mac in a few minutes.

You need Node 24 or newer. For the app you also need Xcode and XcodeGen. Everything runs in fake Apple mode, so nothing paid is ever called.

1. Start the backend
git clone https://github.com/abozaralizadeh/ScrollTax.git
cd ScrollTax/backend
npm install
cp .env.example .env
# put a long random string in SESSION_SECRET:
#   openssl rand -hex 32
npm run dev
2. Open the app
cd ScrollTax/ios
xcodegen generate
open ScrollTax.xcodeproj
# run it in the simulator: demo mode
# starts on its own
3. Run the tests
cd ScrollTax/backend && npm test
cd ../ios/Packages/ScrollTaxCore && swift test

Putting the backend on a Debian or Ubuntu server? sudo ./setup_service.sh installs it the first time and updates it after. The README has the rest.

Straight answers

What it is, and what it isn't.

Can I get it from the App Store?

Not yet. Real blocking needs Apple's Family Controls approval, and that part hasn't run on a real iPhone. Right now it runs in the Simulator in demo mode.

Is there a web demo?

No. Screen Time only exists on the phone, so a browser version would be fake. The video at the top is the real app. The toll above is just a toy to show the idea.

Can't I just switch it off?

Yes. You can remove the Screen Time permission or delete the app. It only works for people who want it to, and it doesn't punish anyone for walking away.

Where does the money go?

Nowhere for now. Payments only run in Apple's sandbox or test mode. The price shown is the default setting.

Is this a treatment?

No. It's a tool, not a medical product. If social media is hurting your life, a doctor or counsellor can help.

Can I use the code?

Yes, for anything non-commercial. It's source available under the PolyForm Noncommercial License 1.0.0. For commercial use, ask first by opening an issue.
